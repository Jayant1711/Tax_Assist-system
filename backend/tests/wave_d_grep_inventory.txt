Adaptation disposition (every change documented in a test comment at the
adaptation site; NO test deleted, NO assertion weakened beyond the
mechanical contract change):

  - authed_client / make_session fixtures (tests/conftest.py) replace
    client-supplied session dicts; ids are server-issued uuid4 hex.
  - payload-validation rows move to the server-state write path: the state
    is seeded through the store (tests are trusted writers) and refused at
    the load boundary by the same _validate_session_payload rows (422).
  - client-chosen-id rows (C6) collapse into the server-issued-id contract:
    the wire can no longer carry an id (old-style body -> 422); the
    sanitization units (validation.py, SessionLab, audit logger) are
    unchanged and stay covered by their unit tests.
  - /history tests gain owned rows (foreign -> 404, anonymous -> 401);
    TAX_ENABLE_HISTORY default flips ON (kill-switch retained).
  - old-style bodies are additionally pinned by dedicated contract-422
    tests (test_session_store.py).
