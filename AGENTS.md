# Tax Assist System

## Project Purpose

AI-powered Indian tax advisory platform.

## Tech Stack

Frontend:
- Next.js
- TypeScript

Backend:
- Python

## Global Rules

Never invent tax laws.

Always generate tests.

Always preserve audit logging.

Always document major architectural decisions.

Prefer refactoring over rewrites.

Keep frontend and backend separated.

Review security before major changes.

## Development Process

1. Architect Review
2. Implementation
3. Security Review
4. QA Review
5. Documentation

## Quality Standards

Production-grade code only.

No TODO placeholders.

No hardcoded secrets.

No breaking changes without explanation.
